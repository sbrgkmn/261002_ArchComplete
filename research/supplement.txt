1. Data Augmentation7
To expand the number of samples in the dataset so as to make8
it suitable for learning purposes, we devised an augmentation9
technique to create variations of each 3D house model in the10
dataset. The augmentation process involved rotating each input11
3D model 12 times around its center, with each rotation sepa-12
rated by a 30-degree interval. For each rotation, a predefined13
box — occupying approximately half the input model’s size —14
was used to identify a unique chunk of the model that inter-15
sected with the box. The mesh vertices within this intersecting16
region were then selected and translated along the x-axis vec-17
tor. The scale of the movement was randomized within a range18
of 2 to 5 meters, introducing variability into the augmentations.19
This operation was repeated for all 12 rotations, generating a20
set of 12 distinct augmentations for each input model (see Fig-21
ure 1). Each augmentation resulted in a unique deformation of22
the model, creating diverse distortions while maintaining the23
overall design concept and spatial configuration of the original24
model. The process preserved the vertical dimensions of the25
model, ensuring that floor heights remained consistent through-26
out the dataset. This allowed the architectural fidelity of the27
input models to be retained while modifying their proportions28
in a controlled manner.29

levels of downsampling and three levels of upsampling layers.35
In between the encoder and decoder layers lies the custom Vec-36
tor Quantization Layer with an embedding table that is initial-37
ized to learn a codebook of local volumetric patch embeddings.38
We measure the L2-normalised distance between the flattened39
encoder latent feature map and code words of this codebook.40
