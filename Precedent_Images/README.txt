98 dataset precedents · 632 image files · 479 images at least 1000 px on the longest edge · 5 precedents with missing view types

Open index.html for the visual browser. Each named folder contains original-resolution downloads, an image browser, dataset_identifier.txt, README.txt, and sources.csv / sources.json. Image filenames use the dataset precedent name and view type.

Coverage targets: at least 2 exterior views, 1 interior view, and 1 floor-plan image. Where a project was unbuilt, model photographs/renderings/drawings are labelled as such. A met count does not assert that all material is a built photograph or an original architect-issued plan.

The public dataset contains 98 distinct identifiers across its original and augmented folders. These folders follow that released union. Published names and dataset spelling differences are explained where needed. Meisterhaus is matched to the double-house type; its specific individual house remains uncertain.

Quality: higher-resolution publicly accessible originals were preferred and source transformations were removed when available. No AI upscaling or invented images. Some historic/private/unbuilt precedents are documented only in small web reproductions; dimensions and low-resolution counts are explicit in the index. Toy Block House I interior panels are photographed book-preview extracts. Some plans are student redrawings, labelled in the relevant folder notes.

All image files were decoded/verified, exact duplicates within folders removed, and dimensions checked. Source pages and image URLs are recorded per file. The collection is for reference; it does not convey image rights or publication licenses.
